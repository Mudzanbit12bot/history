# Публикация на GitHub Pages

Приложение — статический сайт: сборка, Node.js и серверная часть для чтения материалов не требуются.

1. Отправьте файлы репозитория в GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку публикации и каталог `/ (root)`, затем сохраните настройки.
5. Откройте выданный GitHub Pages URL. `index.html` использует относительные пути, поэтому поддерживается публикация в подпапке репозитория.

JavaScript-модули не запускаются надёжно через `file://`. Для локальной проверки используйте, например, `python -m http.server 8000`.

## Ограничения публикации

GitHub Pages не запускает backend. Индивидуальный прогресс остаётся в браузере студента; Live Classroom отдельно использует Firebase Realtime Database и работает только после настройки Authentication и правил из [FIREBASE_SETUP.md](FIREBASE_SETUP.md). Автоматическая проверка Live Classroom выполняется в клиенте и не является защищённой серверной оценкой. QR-код вычисляется локально в браузере после загрузки библиотеки `qrcode` с jsDelivr; без доступа к CDN можно использовать код и ссылку. Firebase SDK также загружается с Google's CDN при открытии Live Classroom.
