# HISTORY://2077 — Digital History Archive

Статическая адаптивная учебная платформа по истории Руси и становления Российского государства. Реализованы шесть учебных модулей (от ранних князей до объединения земель вокруг Москвы), словарь, хронология, личности, практическое задание, письменные ориентиры, тесты трёх уровней, кроссворды и шесть разных игровых механик.

**Автор проекта:** Рябчук Иван Андреевич.

## Запуск

Сборка и установка зависимостей не нужны. Нужен любой локальный HTTP-сервер, потому что приложение использует JavaScript-модули:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`. При публикации на GitHub Pages используется та же статическая версия.

## Что работает

- Навигация между разделами, карточки шести модулей и подробные учебные материалы.
- Проверочные задания трёх уровней: по 10 вопросов на каждый уровень каждого из шести модулей. Порядок вопросов и вариантов ответов перемешивается; каждая попытка получает номер варианта.
- Закрытые задания проверяются автоматически. Открытые ответы уровня 3 показаны для самопроверки и **не оцениваются автоматически**.
- Тематические кроссворды с посимвольными клетками, проверкой и сбросом.
- Шесть разных игр: хронология, квест, историческое расследование, сопоставление земель, анализ последовательности нашествия и сопоставление правителей.
- Две командные викторины по пяти темам, с вопросами на 10–50 баллов. Ведущий открывает ответ и начисляет баллы выбранной команде; названия, счёт, использованные вопросы и журнал сохраняются в браузере.
- Индивидуальная история тестов, отметки изученных тем, избранное, печать и экспорт результатов в CSV.
- Кнопка «Очистить данные» в меню и настройках с двумя подтверждениями. Удаляются локальный прогресс и результаты сайта, но не файлы приложения.
- Live Classroom через Firebase Realtime Database: преподаватель входит по почте и паролю, создаёт занятие, ученики подключаются по коду/QR, а результаты появляются у преподавателя в реальном времени.
- Автоматическая проверка тестов, кроссвордов и игр внутри Live Classroom; для запуска не нужны VPS, npm или сборка.
- В Live Classroom на каждого ученика разрешена одна отправленная попытка. Преподаватель может аннулировать её в списке ответов, чтобы разрешить повторное прохождение.
- При подключении ученик подтверждает передачу имени и доступной браузеру сводки устройства; преподаватель видит её в списке участников.

## Ограничения, которые важно знать

Индивидуальный прогресс хранится в `localStorage` текущего браузера. Live Classroom начинает синхронизировать данные после настройки Authentication и правил Realtime Database по инструкции в `docs/FIREBASE_SETUP.md`. Автопроверка выполняется в браузере ученика, поэтому результат можно подменить; не используйте его как защищённую официальную оценку. Браузер может не раскрыть точную модель устройства; собирается только предоставленная браузером сводка модели/типа, ОС и браузера, без IMEI/серийных номеров, IP, геолокации или отпечатка устройства. Ограничение повторной попытки привязано к анонимному аккаунту Firebase: новый браузер или очистка его данных создаёт другой вход. Любой, у кого есть код/ссылка, может подключиться к открытой сессии; не отправляйте чувствительные данные.

QR-генератор подключается из jsDelivr. Если библиотека или сеть недоступны, остаются текстовая ссылка и код. Google Fonts также загружаются извне; при недоступности используются системные шрифты.

В материалах различаются летописный рассказ, поздняя рукописная традиция и современная интерпретация; спорные даты помечены как условные. Приведённые в интерфейсе письменные памятники — ориентиры для дальнейшего чтения, не постраничная академическая библиография. Перед использованием в оценочной работе сверяйте формулировки и критерии с учебником и преподавателем.

## Структура

- `index.html` — точка входа.
- `src/data.js` — учебные материалы, вопросы и кроссворды.
- `src/main.js` — навигация, тестирование, игры, локальное сохранение.
- `src/firebase-classroom.js` — подключение Live Classroom к Firebase.
- `database.rules.json` — правила доступа Realtime Database.
- `styles.css` — адаптивная дизайн-система.
- `docs/DEPLOYMENT.md` — публикация на GitHub Pages.
- `docs/FIREBASE_SETUP.md` — настройка Firebase Authentication и Realtime Database.
